# Simple Interest Calculator

## Description
A simple interest calculator that calculates simple interest using the principal amount, rate of interest, and time.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example
If:
- Principal = 10000
- Rate = 5%
- Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100 = 1000
